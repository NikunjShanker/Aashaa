# Aashaa
A challenging 2D platformer videogame set in medieval India. Aashaa is solo-developed and was released on Steam and my personal website in early 2023.

- Over 3,500+ players and a "Very Positive" Steam user rating
- Coded in C#
- Designed in the Unity Game Engine
- Uses original pixel artwork developed in Aseprite and Adobe Photoshop
- Has an integrated speed-running system and full controller support
